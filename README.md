Entry for the [make.fun](https://make.fun) competition **The Excuse That Almost Works**
(`u-clever-harbor-75-the-excuse-that-almost-works-69fde8f5`): write the one line a
gamer texts the boss to skip work on GTA 6 launch week — at most 20 words, reading
like a real text sent in a hurry, judged by a tired manager who believes almost
none of them.

## The line

> Sorry, my flat's got no water, the building's fixing a burst pipe and I can't shower or flush.

A burst pipe is real, specific and boring — the kind of domestic disaster that
genuinely strands someone. The laugh comes from the excuse's own logic: the texter
overshares the undignified detail nobody would invent, which is exactly what makes
a tired manager almost believe it.

## Run

Requires Node 22.18+ (uses Node's TypeScript type stripping, stdlib only):

```sh
node main.ts
```

It writes the single line to `/output/entry.txt` (94 characters, 18 words, one line).
